# Covers

Read [the execution contract](../sadeq-studio/references/execution.md) first to resolve the existing runtime/project and preserve independent works. Read the relevant source context before proposing edits. Read the selected work context, actual exported video if current, and styles.md. Use a clear factual source frame or supplied photo tied to the video's topic. Extract a frame with available local FFmpeg using a verified timestamp; preserve the source. Use available image-generation/editing/design tools for requested design, inspecting the source image before edits. Don't invent a person's likeness, product capability, testimonial or offer.

Use concise accurate Arabic, readable at phone size, with the project font/palette and no text over the key face/product. Consider the requested destination/crop; verify current platform specs when asked for platform-specific dimensions instead of asserting a permanent grid rule. Preview the actual finished image and return its real path. Alternatives should express distinct truthful hooks when requested.

The cover is a separate image deliverable. Studio has no image layer/automatic first-frame-cover insertion API; don't claim the cover is attached to a timeline or publish it. If insertion is explicitly requested, identify the missing integration or use a verified separately authorized editor/render path. Never run original external thumbnail scripts that aren't shipped in this plugin.
