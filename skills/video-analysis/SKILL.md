# Video analysis

Read [the execution contract](../sadeq-studio/references/execution.md) first to resolve the existing runtime/project and preserve independent works. Read the relevant source context before proposing edits. Read [analysis.md](../sadeq-studio/references/analysis.md). Inventory actual assets and cached records. First ingestion covers the linked library; existing project requests reuse source-matching cache and select changed/new files explicitly. Run analyze and poll status, then fresh context. Never claim complete analysis while failures/pending/stale sources remain.

Use context --asset IDs for relevant clips and inspect their cached frame images. Take subject/action, composition/palette, visible typography, source speech and uncertainties separately with times. Find useful ranges for this brief; don't choose a shot merely from its filename. ASR includes full-audio segment/word times but remains automatic. TXT/SRT are source-time transcripts, distinct from rewritten overlay copy and timeline timing. To choose repeated takes, continue with speech-edit.
