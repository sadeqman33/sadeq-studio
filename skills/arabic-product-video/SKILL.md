# Arabic text

Read [the execution contract](../sadeq-studio/references/execution.md) first to resolve the existing runtime/project and preserve independent works. Read the relevant source context before proposing edits. Read [styles.md](../sadeq-studio/references/styles.md) and [timeline-plan.md](../sadeq-studio/references/timeline-plan.md). For Iraqi-market product ads use natural wording from the current brand and audience. Separate verbatim captions from promotional copy. Verify names, prices, units and specifications; a reference asset/library icon doesn't prove compatibility.

Take one useful message per visible phrase: match a demonstrated benefit or complete spoken clause. Keep copy readable at phone scale; independent text layers permit up to 500 characters but short phrases are preferred. Do not force a CTA onto an informational/emotional request. Inspect the frame before choosing layer x/y/width; protect faces/product/logo/existing captions. Preserve Arabic shaping/RTL, intentional line breaks and mixed Latin prices/numbers. Use the locally available project-approved Hacen Beirut/Alexandria font, per-layer color and size; no silent substitution or redistribution.

Use top-level independent text layers for new designs (clips.text empty) with GLOBAL start/end and a readable hold/clean exit. Choose plain/kinetic/paper/fade/pop/blur deliberately. Keep source speech complete; changing displayed copy does not require cutting the recording. Existing legacy captions remain clip-relative (<=90 characters, textStart/textEnd/textY). Individual timed word layers are supported; prefer local transcript word times for spoken captions and label manually estimated word timing. Sentence-wide karaoke highlights and animated underlines remain unconnected.

For requested static feature icons/photos, use legitimate supplied assets or available image tools, preserve licenses, import the local PNG/JPEG/WebP through workflow.py import-image, refresh context and create image/icon layers referencing overlay_assets IDs. Size/position/opacity/rotation and the same motion presets are editable; no arbitrary SVG/URLs/unsupported plan fields. Every designed text/photo/icon should be a separate editable timeline lane, not burned into a source video.

Preserve original color and audio unless the current request says otherwise. After rendering, inspect entrance/hold/exit and important cuts. For distinct concepts read meta-ads-diversity; for audience review read iraqi-video-review only when useful/requested.
