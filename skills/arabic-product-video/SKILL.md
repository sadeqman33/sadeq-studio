# Arabic text

Read [the execution contract](../sadeq-studio/references/execution.md) first to resolve the existing runtime/project and preserve independent works. Read the relevant source context before proposing edits. Read [styles.md](../sadeq-studio/references/styles.md) and [timeline-plan.md](../sadeq-studio/references/timeline-plan.md). For Iraqi-market product ads use natural wording from the current brand and audience. Separate verbatim captions from promotional copy. Verify names, prices, units and specifications; a reference asset/library icon doesn't prove compatibility.

Take one useful message per visible phrase: match a demonstrated benefit or complete spoken clause. Keep it short enough to read at phone scale, within 90 characters per overlay. Do not force a CTA onto an informational/emotional request. Inspect the frame before choosing top/middle/lower textY; protect faces/product/logo/existing captions. Preserve Arabic shaping/RTL and intentional line breaks; keep mixed Latin prices/numbers legible. Use the current available work font; no silent font substitution or redistribution.

Choose plain/kinetic/paper/fade/pop/blur or inherit deliberately. Set textStart/end relative to the trimmed clip, with a readable hold and clean exit. The current engine has phrase-level overlays, not a separate per-word karaoke/highlight layer. Contiguous trim splits can change phrases while keeping full speech; check joins. Feature-icon and animated underline design requests need an actual rendering path; don't put invented fields in plans. For icon assets use legitimate sources/available image tools and preserve licenses; an exported icon alone is not a connected timeline overlay.

Preserve original color and audio unless the current request says otherwise. After rendering, inspect entrance/hold/exit and important cuts. For distinct concepts read meta-ads-diversity; for audience review read iraqi-video-review only when useful/requested.
