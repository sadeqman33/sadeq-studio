# Project memory

Read [the execution contract](../sadeq-studio/references/execution.md) first to resolve the existing runtime/project and preserve independent works. Read the relevant source context before proposing edits. Read context --project ID and its initialized flag, memory_revision, memory_warnings and identity. For a linked new project use analyze --project ID --all once; for existing projects analyze only selected new/changed assets and retrieve fresh context. Do not create another registry or rerun the whole library for each request.

Read PROJECT.md/STYLE.md/LEARNINGS.md through context memory_files. Keep supplied facts, observed style, uncertainty and user-pinned direction distinct. Import only lasting approved feedback into the same project's marker sections; retain generated sections and references. The memory module validates and synchronizes edits on project access. Invalid markers require repair before dependent generation, preserving the original text.
