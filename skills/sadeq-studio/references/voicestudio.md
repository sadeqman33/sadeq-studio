# VoiceStudio local narration — Studio 0.20.0

VoiceStudio 0.5.7 runs independently, normally at http://127.0.0.1:3900. Its app/runtime/model files and generated recordings stay outside the public plugin package. Install the official Apple Silicon app; select MLX-Audio and download/select mlx-community/VoxCPM2-8bit (about 3.23 GB). The model card declares Apache-2.0 and Arabic support. The default OmniVoice model has separate noncommercial terms; do not substitute it silently. No model/provider switch is performed during narration.

Check `GET /api/voicestudio` or `python3 workflow.py voice-status` for connected/ready, model identity and discovered voice profiles. Ready requires a responding service, available MLX backend, matching selected model and installed weights. If setup is incomplete, show the error and fix setup with the user's authorization; don't pretend an alias is a real voice or launch another service. Optional local env: SADEQ_VOICESTUDIO_URL (HTTP loopback only); SADEQ_VOICESTUDIO_API_KEY for a protected local service. Neither belongs in Git. The adapter bypasses proxy settings and refuses redirects.

The explicit Generate button first saves the work, then posts id, work_id and base_fingerprint to /api/voiceover-generate. It uses saved voiceover.text (1–4096 characters), dialect, voice description, direction and voiceProfile (default or a discovered saved profile). Text is synthesized as Arabic through /v1/audio/speech with model=mlx-audio and WAV response. Direction is an engine hint, not a guaranteed accent or emotion. It does not translate the script or clone anyone by default. Preview a short sentence first; inspect Arabic pronunciation and Iraqi idiom before a longer job.

A generated WAV is checked by FFprobe, converted to the existing local audio format and appended as a new project audio asset. The exact work and edit fingerprint are rechecked before attaching; a stale-work result leaves the recording on disk and reports its path instead of changing another draft. Existing assets, offset, gain and originalGain are preserved. The new recording is enabled with its full trim interval. Undo/history and asset selection allow returning to the old recording. Warn if it exceeds video duration; do not silently speed up speech or extend footage.

Use the standalone audio player to audition; the voice lane controls timing and volume in the video. Real generated audio, model identity and generation text are private local provenance. No automatic external provider fallback, uploads, voice cloning, paid services or model downloads are authorized by opening this panel. Do not claim an Iraqi accent is verified until listened to; an ASR match checks wording only, not naturalness or speaker identity.

Sources: https://github.com/debpalash/VoiceStudio and https://huggingface.co/mlx-community/VoxCPM2-8bit . VoiceStudio is AGPL-3.0; it remains a separate installed application with its own notices.

VoiceStudio 0.5.7 setup caveat: its first-run wizard may still request the default OmniVoice model after MLX/VoxCPM2 has been selected. Do not download or accept another model just to dismiss that wizard. The local speech API and Studio readiness check can operate with the installed selected VoxCPM2, as verified with real Arabic samples. Keep VoiceStudio running while using Studio narration.
