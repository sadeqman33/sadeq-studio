# Montage

Read [the execution contract](../sadeq-studio/references/execution.md) first to resolve the existing runtime/project and preserve independent works. Read the relevant source context before proposing edits. Use video-analysis to inspect relevant shot ranges. Build the requested visual progression: establishing context, useful details/action and a coherent ending. Vary framing and select readable moments rather than include every library file. Use saved identity/feeling without forcing captions or a talking-head workflow on silent/ambient footage.

Preserve ambient/original audio unless the brief calls for a mute or the user's chosen background track. Verify actual audio presence; filenames don't establish silence. Optional text follows arabic-product-video. A beat-aligned request requires listening/measuring the supplied track and choosing actual cut times; automatic beat detection, shake/flash/zoom effects are not connected. Don't claim these effects from sequential cuts alone.

Read timeline-edit for the independent work and export-video for the actual deliverable. No arbitrary universal shot length or mandatory no-text rule: follow this brief. Keep source colors unless asked to adjust them. Preserve unused sources and older works.
