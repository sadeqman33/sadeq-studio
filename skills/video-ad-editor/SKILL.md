# Reels and ads

Read [the execution contract](../sadeq-studio/references/execution.md) first to resolve the existing runtime/project and preserve independent works. Read the relevant source context before proposing edits. Use video-analysis for relevant evidence and speech-edit for repeated takes. Read arabic-product-video for copy/placement and the shared styles guide. Start from the requested feeling and goal: choose a truthful relevant opening, visible evidence/development and appropriate ending. Use the actual saved offer; avoid invented urgency/testimonials or generic ad copy that replaces the brief.

Select source ranges that finish the idea and shots supporting each clause. Keep original audio/colors by default. Portrait or landscape framing uses the supported ratio with contained source footage; no automatic face tracking or reframing is connected. The user may accept bars or provide better framing rather than stretch a face/product.

Read timeline-edit and submit a named NEW work unless the user asked to revise an exact existing one. For requested videos continue with export-video and return the editable link. Do not execute the old external plugin's script paths or assume its 3D/collage/word-caption engine is installed in Sadeq Studio. External-editor requests route to davinci-video only when explicit.
