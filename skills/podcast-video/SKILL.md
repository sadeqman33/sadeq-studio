# Podcast clips

Read [the execution contract](../sadeq-studio/references/execution.md) first to resolve the existing runtime/project and preserve independent works. Read the relevant source context before proposing edits. Use video-analysis and speech-edit on the episode. Select excerpts with a complete premise/development/payoff, retaining surrounding context and conditions. A clear written hook is useful when it accurately summarizes the excerpt, not a mandatory invented sensational claim. Write it using arabic-product-video and protect the speaker's face.

For multiple requested reels create one named work each. For a full landscape episode use 16:9 and actual source duration; do not substitute short reels. Don't cut an answer so it reverses its qualification or presents a separate sentence as a response to another question. Review joins and audio synchronization using tools that actually listen/play.

The current Studio supports sequential source trims, not multicamera audio sync, angle automation, face tracking or overlapping picture-in-picture. Multiple angles may be cut sequentially only from verified synchronized source ranges; don't infer offsets from filenames. An explicit unsupported multicamera brief requires its concrete integration gap to be stated before claiming an edited result. Use timeline-edit/export-video for supported excerpts and retain sources.
